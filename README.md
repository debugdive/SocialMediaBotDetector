# 🤖 Social Media Bot & AI Detection Suite

Complete Machine Learning project featuring:
1. **Instagram Bot & Deepfake Detector** (Flask backend + Chrome Extension / Web App)
2. **AI vs Human Text Detector** (Streamlit Application)

---

## 🚀 Setup on Any New Laptop (Quick Start)

### Step 1: Install Python
Make sure **Python 3.10+** is installed on the laptop (download from [python.org](https://www.python.org/) or Microsoft Store).  
*Important: During installation, check the box that says **"Add Python to PATH"**.*

### Step 2: Open Terminal / Command Prompt in this folder
Open VS Code (or regular PowerShell / Command Prompt) and navigate into this folder:
```bash
cd SocialMediaBotDetector
```

### Step 3: Install all dependencies in one command
```bash
pip install -r requirements.txt
```

---

## 🎯 How to Run the Applications

### Project 1: Instagram Bot Detector (Backend & Extension / Web Clone)
1. Run the Flask server:
   ```bash
   python app.py
   ```
2. **Option A (Chrome Extension on real Instagram):**
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable **Developer mode** (top right toggle).
   - Click **Load unpacked** (top left button) and select the `extension` folder inside this project.
   - Go to any Instagram profile (e.g. `rohitsharma45` or `lilmiquela`) and click the pink **"🤖 RUN PROFILE SCAN"** button!
   
3. **Option B (Standalone Web Clone):**
   - In any browser, simply open: `http://127.0.0.1:5000`

---

### Project 2: AI vs Human Text Detector (Streamlit)
1. Open a new terminal / command prompt tab in this folder.
2. Run:
   ```bash
   streamlit run ai_detector.py
   ```
3. A browser tab will open automatically. Paste text generated by ChatGPT (detects AI) or typed naturally (detects Human).

---

## 📁 Project Structure
- `app.py`: Flask backend with ML models (TF-IDF + Logistic Regression) and endpoints.
- `ai_detector.py`: Streamlit application for AI vs Human text classification.
- `extension/`: Chrome Extension to inject scanner into real Instagram pages.
- `templates/` & `static/`: HTML/CSS for the standalone web clone.
- `requirements.txt`: List of all required Python packages.
- `Presentation_Slides.pdf`: PDF containing slide summaries and presentation speaker notes.
